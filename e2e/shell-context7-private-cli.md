# Stock CLI session with a reviewed source extension

The `shell_context7_registration` Guest harness can run the owned
`GENTLE_EXPERIENCE_PRIVATE_CONTEXT7_CLI_PROBE=1` test mode. It verifies the original
frozen Pi1.0.0 archive against the committed lock before extraction, then starts
its actual `dist/bundle/cli.js` with the reviewed private Context7 extension.

`--extension … --no-session --print /mcp` uses real CLI startup and built-in MCP.
The controlled Separate target receives default SDK storage; Shared files and
private policy bytes/inodes/modes/mtimes remain unchanged. On discovers the local
fixture's tool; off and a disabled same-name global entry make zero HTTP requests.
Each child requests a 15-second SIGKILL timeout and receives explicit stdin EOF.

**Discovery is not a canonical status readback.** Frozen print mode emits empty
stdout and stderr for `/mcp`, even with a connected fixture. The test records
this gap rather than treating exit0 as Ready. It does not call a tool through the
agent pipeline or contact the real Context7 service. It loads a reviewed source
extension explicitly—not a new published Gentle SDK distribution or installed
product—and does not qualify Darwin, Windows or a complete installed lifecycle.

The shared Go wrapper retains its 60-second aggregate context, process-group
cancellation and bounded pipe drain. The inner Node timeout alone is not a
15-second full-tree wait proof. All source assertions remain retained; no
probe is executed during recovery and no installed or escaped-descendant
settlement guarantee is added.
