# Canonical staged MCP in a frozen SDK session

The existing Linux registration controller's
`GENTLE_EXPERIENCE_CANONICAL_CONTEXT7_PROBE=1` mode prepares five real Separate
stages and passes them to `shell-context7-stage-session.mjs`. The original Pi1.0
archive is authenticated before execution; dependencies remain read-only.

The fixture imports only the frozen package root's public SDK APIs. SDK sessions
need an explicit built-in `createMcpExtension()` factory; no private extension,
registration callback or internal credential-store module is loaded. Both the
loader option and `PI_CODING_AGENT_DIR` select the physical private staged agent.
Public `ModelRuntime` disables network catalog refresh; `modelsPath:null` is an
in-memory catalog, not evidence that a model-store file was redirected.

| Case | Same-session observation |
|---|---|
| Staged off | Raw `/mcp` disabled/codemode text; no project fixture contact/tool |
| Nil profile | No canonical MCP file; raw no-servers notification |
| Built-in disabled | No MCP command; never send an unknown command to a model |
| Trusted project on | Local project replaces global off; discovery/direct tool present |
| Untrusted project | Project ignored; canonical off remains disabled |

Trust is explicitly supplied by the SDK fixture, not CLI/human consent. The
loopback URL appears only in project configuration; the staged official URL is
never rewritten or intercepted. All fixture HTTP is counted before guards,
including rejected GET; discovery sends no `tools/call`. Repeated manager queries
preserve text and do not open another connection. Project/config/shared whole
preimages and original MCP file bytes/identity/mode/mtime remain intact. Owned
private SDK metadata initialization is recorded, not hidden as zero writes.

This is a new SDK session, not an existing CLI/TUI or Gentle-Pi product startup.
Raw manager text is presentation, not structured endpoint/source readback or a
Ready receipt. No assistant/model call, permission execution, actual Context7
service health, Windows/Darwin runtime or installed-product acceptance is proven.
Public nonnil profile and generic/Windows Context7/RDD refusals remain unchanged.

This reconciliation retains the complete fixture as source only. No new SDK
session, model, permission, service or installed-runtime execution is performed.
The bounded Go wrapper remains a test controller, not a product startup gate.
