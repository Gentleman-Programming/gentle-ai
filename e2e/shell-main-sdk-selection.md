## Contract

   adjunct using the existing actions.
2. `select-main-sdk-package` repeats stock acquisition, graph, lock, supplier,
   native, settings and complete composed-runtime checks before writing.

   `FINAL_ROOT/runtime/main-sdk` in the private `agent/settings.json`.
4. `verify-main-sdk-selected` requires that declaration and repeats the same
   stock and composed-runtime checks without repairing any drift.

All other settings and declarations survive. Selection refuses Shared,
non-Linux-amd64, nonprivate prefix/agent bindings, published `installation.json`,
duplicate/filtered stock declarations, preselected Main, and non-0600 or
multiply linked settings, and non-0700 or changed physical agent identity.
Ordinary stock verification still requires stock;
only the explicit selected verifier accepts the composed package binding.
The existing exclusive-write/sync/rename primitive is used. A failed outer
readback is not an atomic rollback guarantee.
