# Sealed original-installer re-entry

`internal-native-produce` is an internal transport, not installation authority.
It carries the private producer root, sibling publication stage, original
operation deadline and existing five-value install selection/profile.

Before executing the selected original installer, Linux amd64 requires the
live sealed execution guard, the actual bounded parent operation slice, exact
embedded source descriptor, pinned bootstrap Node and physical confirmation.
The deadline must be unexpired and cannot exceed 140 seconds from inspection.
A native result without verified publication is a refusal, not install success.
The installed success message remains identical to the existing entry.

Other Linux architectures refuse this path. The ordinary TUI and fresh-install
coordinator must still launch it through protected service custody; this entry
does not prepare sources, create a manager, acquire privileges or wire that flow.
