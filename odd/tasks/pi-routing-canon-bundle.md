# Pi routing canon in the provider-contract bundle

Objective: one source for the ODD routing canon shared with Gentle Shell (gentle-pi); gentle-ai renders the Pi block,
including Pi's own clauses, and publishes it in the provider-contract bundle that gentle-pi already vendors under a SHA
lock. Branch `feat/pi-routing-canon-bundle` from `4b65ee67`. Delivery: single PR (user). Runner: `go test ./...`.
Design note: gentle-shell-bench `docs/canon-design-note.md` (roadmap T10/T11, spec R3).

## Specs

- S1 (roadmap R3, verbatim): "One source for the canon. The ODD routing canon lives in gentle-ai
  (`internal/components/agentguidance/routing.go`) and is copied into gentle-shell by hand (harness step text, assets)
  plus a vendored fixture; a change in one repo must reach the other without manual mirroring."
- S2 (user decision, verbatim): "(a) con cláusulas Pi en gentle-ai" — option (a): gentle-ai renders the routing block
  into a published artifact gentle-shell consumes at build time; `RenderRouting(AgentPi)` emits the Pi-specific
  clauses that gentle-pi today adapts by hand.
- S3 Pi clauses: the rendered Pi block carries the wording gentle-pi uses today in its harness ODD steps
  (gentle-pi `extensions/gentle-ai.ts` lines ~1403-1413 at `eebaf274e`: the visible `todo` projection in step 5, the
  "orchestrator's Mechanisms" routing and todo projection updates in step 6, its step 7 closing, the phase reporting
  and resume lines), branching per agent the way RDD and the Codex tail already branch. Other agents' rendered output
  stays byte-identical (assumption: no change for non-Pi agents).
- S4 Bundle entry: the provider-contract bundle gains one entry with the rendered Pi routing block, generated by the
  existing `providercontractbundlecmd generate` path, with a minor `CONTRACT_SEMVER` bump, an "introducing" version
  field following the existing pattern (`bundle.go:52-63`), the file-count bound updated, and release verification
  (`scripts/verify-release-assets.sh`, `release.yml`) accepting it if they enumerate entries.
- S5 Unchanged: gentle-ai still writes nothing into Pi's prompt files (`cli/run.go` "Pi owns its prompt delivery").
- S6 Phase 2 (gentle-pi, later task): mirror the new bundle, inject the routing block from the mirror, compare the
  ratchet and literal tests against it, and remove `scripts/mirror-odd-routing.mjs` and the hand-adapted copies.
